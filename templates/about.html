IEEE Project #35 — Machine Learning Domain

"From Data to Decisions: The Power of Machine Learning in Business Recommendations"

System Name: SmartBiz AI | Built with Python, Scikit-Learn, Pandas & Django

1. Problem Statement

Modern retail enterprises collect massive transaction volumes daily. However, transforming raw transactional records into actionable customer intelligence and personalized product recommendations remains a key operational challenge. Without automated segmentation, businesses fail to identify VIP customers or deliver targeted recommendations, leading to lower customer retention and missed revenue opportunities.

2. Project Objective

SmartBiz AI solves this challenge by implementing an end-to-end Machine Learning pipeline using real-world e-commerce transaction data. The primary objective is to automatically segment customers based on behavioral RFM parameters (Recency, Frequency, Monetary) and generate personalized product recommendations to drive business growth.

3. Dataset Description

The project strictly utilizes the authentic Online Retail.xlsx dataset, containing 541,909 raw transactions from a UK-based online retail enterprise spanning 373 days across 38 countries.

  • Original Rows: 541,909
  • Cleaned Rows: 392,692
  • Unique Customers: 4,338
  • Total Revenue: £8,911,407.90
  • Cleaning Rules Applied: Excluded missing CustomerIDs, cancelled invoices ('C'), negative quantities/prices, and duplicate records.
4. Machine Learning Methodology
A. RFM Feature Engineering

Aggregates raw customer transactions into Recency (days since last order), Frequency (unique order count), and Monetary (total spend £), plus supporting metrics like Avg Order Value and Unique Products.

B. K-Means Clustering

RFM values are log-transformed and standardized. K-Means clustering is evaluated across K=2 to 8. K=2 was selected as the optimal model with a Silhouette Score of 0.4328.

C. Recommendation Engine

Implements segment-aware collaborative filtering. Identifies top items popular within the customer's cluster while filtering out items they have already bought.
